## Workspace

The workspace got a brand new toolbar.

![New toolbar](../../Resources/posts/whats-new-in-xcode-27/images/87CC0651-EF2B-42B4-9C18-035A0429DF75.png)

Build Activity has moved below the project title.

![Build Activity below the project title](../../Resources/posts/whats-new-in-xcode-27/images/73D085B0-04D8-45C0-BCC6-B8BA0BCE9F6A.png)

There is a new entry point for the coding agent right from the toolbar, and the scheme and destination selectors are now middle-aligned.

![Coding agent entry point and middle-aligned selectors](../../Resources/posts/whats-new-in-xcode-27/images/8478DC9F-40BB-4332-987E-76C808A57DAE.png)

The Git branch picker moved to the bottom so it can show the full branch name.

![Git branch picker moved to the bottom](../../Resources/posts/whats-new-in-xcode-27/images/E60A7D3B-56E7-4212-BF22-6312480C42DB.png)

There are new themes, and they can now be set differently for each project or workspace. One handy use case is distinguishing between two worktrees of the same project.

![New themes](../../Resources/posts/whats-new-in-xcode-27/images/07304354-29A0-4828-86B8-F375D718E049.png)

![Per-workspace theme selection](../../Resources/posts/whats-new-in-xcode-27/images/CF74E416-981B-4788-BD28-0EEFEAB55FED.png)

![Theme applied to a workspace](../../Resources/posts/whats-new-in-xcode-27/images/5E9DE596-3FAF-4456-8570-709F4F37494F.png)

Warnings and errors are now surfaced more subtly while editing.

![Subtle warnings and errors while editing](../../Resources/posts/whats-new-in-xcode-27/images/156AD4B3-7DF6-485E-A233-BFF7BE479F44.png)

## Projects and files

There is a new project creation flow — the previous template picker is no longer the default window, though you can still access it.

![New project creation flow](../../Resources/posts/whats-new-in-xcode-27/images/38BCBE56-2351-4EA6-9701-29AC735A5BFB.png)

When you create an app from the new entry point, it starts as **Untitled** and asks for a name when you exit or close the project, just like other document-based apps. It also starts your app without a team ID or bundle ID, and by default targets iPhone, iPad, and Mac.

![Untitled app, named on close](../../Resources/posts/whats-new-in-xcode-27/images/BDE9A2F5-38B8-4B6D-9476-806929B5595A.png)

Opening a Swift file now opens it as a workspace you can build — imagine some SwiftUI code that you can preview on simulator or device and run a playground view for.

![Open a Swift file as a buildable workspace](../../Resources/posts/whats-new-in-xcode-27/images/FFA9AA41-E304-4F6A-AD7B-18C285772F76.png)

One thing I noticed while trying this out is that Xcode adds a comment to the Swift file — I'm guessing to remember the last selected SDK.

![Comment added to the Swift file](../../Resources/posts/whats-new-in-xcode-27/images/EA675B5A-A2EA-4994-A25C-CDB2195DECA4.png)

![Last selected SDK comment](../../Resources/posts/whats-new-in-xcode-27/images/C85A2796-7DA1-4D8A-B812-3B035CF7F140.png)

![Running the single-file workspace](../../Resources/posts/whats-new-in-xcode-27/images/8620A564-B9EB-4743-9EE5-2CD2385FFF34.png)

## Intelligence

The focus this year was on improving the integration to be able to handle parallel agent tasks and conversations.

The AI sidebar has become a complete editor view.

![AI sidebar as a full editor view](../../Resources/posts/whats-new-in-xcode-27/images/A3FF8CBD-2566-4D87-8407-5549D729D522.png)

Agent Q&A prompts now render as a structured native popup with hierarchical nesting.

![Structured native agent prompt popup](../../Resources/posts/whats-new-in-xcode-27/images/918C5E14-768F-47C4-813E-D25F87FD3DC7.png)

The markdown files generated by agents are now rendered side by side with the conversation, making it easier to review the plans.

![Agent-generated markdown rendered side by side](../../Resources/posts/whats-new-in-xcode-27/images/0E756F83-36CB-45A6-881A-142F44284C6F.png)

That same side-by-side view shows the changes — or any other artifacts the AI generates as part of the conversation — being made to your files.

![Side-by-side file changes](../../Resources/posts/whats-new-in-xcode-27/images/CD706E7F-3E29-430C-889B-D2D79B9ADDE9.png)

There is a new conversation list that helps manage multiple agents running in parallel, and you can group conversations into groups.

![Conversation list for parallel agents](../../Resources/posts/whats-new-in-xcode-27/images/65703303-B33D-44F8-B6A8-12142AB35A5F.png)

For more on AI in Xcode, watch **[Xcode, agents, and you](https://developer.apple.com/videos/play/wwdc2026/259/)**.

## Device Hub

An all-new Device Hub replaces the Simulator app. It handles both simulators and connected physical devices, and silently adds the ability to not only control iPhone and iPad but, to some extent, control tvOS, watchOS, and visionOS devices.

![Device Hub](../../Resources/posts/whats-new-in-xcode-27/images/947CCD9A-545A-453C-86EC-936CF2FBA3DB.png)

![Device Hub managing multiple platforms](../../Resources/posts/whats-new-in-xcode-27/images/30485AD3-FB96-466C-83AC-933CA9F6A220.png)

The Device Hub also lets us test for resizability on iPhone (by this point we already know the foldables are coming…).

![Testing resizability on iPhone](../../Resources/posts/whats-new-in-xcode-27/images/0AC197C3-5390-4AE3-AE89-125DC383F1CB.png)

One unique thing I noticed is that it makes it much easier to add and check certs and profiles for both devices and simulators.

![Managing certs and profiles](../../Resources/posts/whats-new-in-xcode-27/images/399DE7FF-7B82-4E7C-AB39-B9F31123FEED.png)

There is an entire session on the Device Hub — watch **[Get the most out of Device Hub](https://www.youtube.com/watch?v=a2N1qAJRFIk)**.

### Updates to Organizer

There is a new overview page in Organizer, surfacing issues from both reports and metrics.

![New Organizer overview page](../../Resources/posts/whats-new-in-xcode-27/images/27D827D2-3C0F-4730-A8E8-2C457E9A1EA0.png)

New metrics tracking for storage and hitches. If only the storage metric had been here earlier, I wouldn't have had to build [StorageAnalyser](https://github.com/gojek/StorageToolKit-iOS) (which I never got a chance to open source).

![New storage and hitches metrics](../../Resources/posts/whats-new-in-xcode-27/images/F608414D-BD65-49B6-9D5F-B15F70D069E6.png)

Scroll Hitches is now replaced by a more general Hitches metric that tracks animation hitches, which includes scroll animations.

![General Hitches metric](../../Resources/posts/whats-new-in-xcode-27/images/D65E7FA1-34EA-4749-9A36-D056555809CA.png)

Last year, Organizer started showing recommendations for launch time. This year, Organizer rebranded it to **metric goals**, which includes more metrics — hang rate, disk writes, battery, storage, and hitches, alongside launch time from before.

![Metric goals](../../Resources/posts/whats-new-in-xcode-27/images/54D4510A-F48C-410C-8380-48FCEFC634E7.png)

There is AI-guided analysis of performance reports like launch time and hitches, as well as for crashes.

![AI-guided analysis of performance reports](../../Resources/posts/whats-new-in-xcode-27/images/28ADAE33-B136-40E9-BCBD-8C85BFFC53FA.png)

By clicking **Generate Analysis**, it explores the codebase, goes through the crash backtrace, pinpoints the code that resulted in the crash, and suggests a fix — which you can ask it to apply as well.

![Generated crash analysis and fix](../../Resources/posts/whats-new-in-xcode-27/images/C5C09A9E-8FB3-4DF5-8E32-A3A75AC22FED.png)
